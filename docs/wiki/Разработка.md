# Разработка

## Клонирование и тесты

```bash
git clone https://github.com/noki4angel37/suggest-bridge.git
cd suggest-bridge
python -m venv .venv
# Windows: .\.venv\Scripts\activate
source .venv/bin/activate
pip install -r requirements-dev.txt
pytest -q
ruff check bot tests
```

CI: pytest на Python 3.11 и 3.12 + ruff на push/PR. Workflow: [.github/workflows/ci.yml](https://github.com/noki4angel37/suggest-bridge/actions/workflows/ci.yml).

## Структура вкладов

См. [CONTRIBUTING.md](https://github.com/noki4angel37/suggest-bridge/blob/main/CONTRIBUTING.md).

1. Issues: ОС, режим, шаги, логи без секретов.
2. PR: узкий diff; для user-visible — строка в CHANGELOG. Свои модули сообщества — локально через `SB_MODULES`, не PR в этот репозиторий (баги ядра и доки — можно).
3. UI-строки бота пока на русском; документация — по согласованию.

|------|------|
| `bot/core/` | Домен и БД |
