# Эксплуатация

Повседневная работа оператора после установки.

## Бэкап SQLite

Критичные данные: заявки, статусы, админы, mirror links, settings — файл `bridge.db` (`BRIDGE_DB_PATH`).

1. Останавливайте бота **или** копируйте согласованный набор: `bridge.db` + `bridge.db-wal` + `bridge.db-shm` (если есть).
2. Храните копии вне хоста бота.
3. Перед обновлением версии — снимок БД.
4. Медиа-кэш (`data/media/`) бэкапьте отдельно при необходимости.

### Restore (runbook)

1. Остановите бота (`docker compose stop` / `systemctl stop`).
2. Снимок текущего `bridge.db` (+ wal/shm) в `bridge.db.bak.<timestamp>`.
3. Подмените файлы из бэкапа **комплектом** одной эпохи. Docker: `./data` → `/data/bridge.db`.
4. Опционально: `sqlite3 bridge.db 'PRAGMA integrity_check;'` → `ok`.
5. Старт → health → `/queue` → тестовая заявка end-to-end.
6. При необходимости восстановите `data/media/` той же эпохи.

## Логи

```bash
docker compose logs -f suggest-bridge
journalctl -u suggest-bridge -f
# Windows: консоль python -m bot.main / run-agent.ps1
```

Полезные строки старта: режим (`mode=`), путь БД, `HOST_ID`, `ROLE`. Ошибки publish/mirror/host-sync — по ключевым словам `PublishRouter`, `mirror`, `host-sync`, `lease`.

## Обычный день админа

1. Модерация карточек в TG и/или Discord — [[Модерация]].
2. `/queue` — застрявшие / отложенные.
3. `/mirror` — если лента разъехалась.
4. Multi-PC: `/host` / `/host_status` перед сменой ПК.

## Failover процесса

- Упал primary → другой агент/ПК забирает lease через `/host` (нужны Syncthing + секрет).
- Два `bot.main` без lease → риск `database is locked` и дублей getUpdates — не делайте так.
- `HOST_ROLE=standby` ждёт `go_primary` не дольше `HOST_STANDBY_WAIT_SEC`.

## Лимиты платформ

| Лимит | Значение |
|-------|----------|
| Текст заявки | 400 символов |
| Discord сообщение | ~2000 (зеркало обрезает) |
| TG caption | 1024 (зеркало обрезает) |
| FSM ответа | 15 мин |
| Lease TTL | `HOST_LEASE_TTL_SEC` (default 60) |

## Рестарт и FSM

Любой рестарт процесса сбрасывает MemoryStorage: незавершённые черновики и «ответ автору» нужно начать заново. Данные в SQLite сохраняются.

Инциденты: [[Устранение-неисправностей]].
