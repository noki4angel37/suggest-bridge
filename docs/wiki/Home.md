# Suggest Bridge

Self-hosted бот **предложки** для Telegram-канала и Discord-сервера.

## Модерация (мок)

```
┌─────────────────────────────────────────────┐
│  ⏳ Заявка #42 · Discord                    │
│  … текст заявки …                           │
│  [ ✅ Одобрить ] [ ❌ Отклонить ]           │
└─────────────────────────────────────────────┘
```

Вымышленные данные. Подробнее: [[Модерация]].
