# Быстрый старт

Цель: поднять Suggest Bridge (открытое ядро Telegram ↔ Discord) на одной машине и проверить `/healthz`. Подробности деплоя — [[Деплой]], переменные — [[Конфигурация]].

## Перед стартом

1. Python **3.11+** (или Docker / Docker Desktop).
2. Заполните `.env` **до** `docker compose up` / первого запуска (плейсхолдер `REPLACE_ME` ≡ «не задано» — код так и трактует).
3. Токены по режиму:

| Режим | Обязательные переменные |
|-------|-------------------------|
| Telegram + Discord | `BOT_TOKEN`, `DISCORD_TOKEN`, `ADMIN_IDS`, `CHANNEL_ID`. Рекомендуется `OWNER_DISCORD_ID` (bootstrap Discord-админа) |
| Только Telegram | `BOT_TOKEN`, `ADMIN_IDS`, `CHANNEL_ID`; оставьте `DISCORD_TOKEN=REPLACE_ME` или закомментируйте |
| Только Discord | `DISCORD_TOKEN`, **`OWNER_DISCORD_ID`**; `BOT_TOKEN=REPLACE_ME` или закомментируйте |

4. Discord: Privileged Intents и invite с правами **268561488** — [[Discord]].
5. Telegram: бот — админ канала — [[Telegram]].

> Не коммитьте `.env`. В примерах — только `REPLACE_ME`, не реальные токены.

Порядок: сначала токены и `.env` ([[Telegram]] / [[Discord]] / [[Конфигурация]]), потом команды ниже.

## Docker (рекомендуется для VPS / Linux)

```bash
git clone https://github.com/noki4angel37/suggest-bridge.git
cd suggest-bridge
bash scripts/deploy/prepare-env.sh
# отредактируйте .env — подставьте ВСЕ нужные токены (не оставляйте REPLACE_ME)
mkdir -p data && sudo chown -R 1000:1000 data   # Linux: non-root user в образе должен писать bridge.db
docker compose up -d --build
docker compose logs -f
curl -s http://127.0.0.1:8080/healthz
```

- База: `./data/bridge.db` (volume `./data` → `/data`).
- Compose задаёт `BRIDGE_DB_PATH=/data/bridge.db` и `HEALTH_PORT=8080`.
- Health слушает **0.0.0.0** внутри контейнера; наружу лучше публиковать только localhost — см. [[Деплой]] и [[Безопасность]].
- Ответ: `"status":"ok"` или `"degraded"` (~30 с на подключение). Если контейнер restart loop — смотрите логи: чаще всего незаполненный `.env`.

**Windows:** `.\scripts\deploy\prepare-env.ps1` вместо bash; нужен Docker Desktop.

## Windows (один ПК, без агента)

На **одном** ПК агент не обязателен:

```powershell
git clone https://github.com/noki4angel37/suggest-bridge.git
cd suggest-bridge
Copy-Item .env.example .env
.\scripts\deploy\prepare-env.ps1
# отредактируйте .env — все токены
python -m venv .venv
.\.venv\Scripts\pip install -r requirements.txt
.\.venv\Scripts\python.exe -m bot.main
```

Альтернатива: zip из [Releases](https://github.com/noki4angel37/suggest-bridge/releases).

## Windows (multi-PC / агент)

Нужен, если несколько ПК и `/host`. См. [[Multi-PC]].

1. Zip из Releases или `/download` в боте.
2. В `.env` на **каждом** ПК: один и тот же `HOST_SYNC_SECRET` (**не** `REPLACE_ME`; иначе агент упадёт на подписи).
3. Syncthing → `HOST_SYNC_DIR` (default `%LOCALAPPDATA%\suggest-host-sync`). Только доверенные устройства.
4. `.\install-agent.ps1` → `.\run-agent.ps1`.

## Linux (systemd)

```bash
git clone https://github.com/noki4angel37/suggest-bridge.git
cd suggest-bridge
sudo mkdir -p /opt/suggest-bridge /etc/suggest-bridge
sudo cp -a . /opt/suggest-bridge/
sudo python3 -m venv /opt/suggest-bridge/.venv
sudo /opt/suggest-bridge/.venv/bin/pip install -r /opt/suggest-bridge/requirements.txt
sudo cp .env.example /etc/suggest-bridge/env
sudo nano /etc/suggest-bridge/env   # заполните токены ЗДЕСЬ — unit читает этот файл, не project .env
sudo cp contrib/systemd/suggest-bridge.service /etc/systemd/system/
sudo systemctl daemon-reload
sudo systemctl enable --now suggest-bridge
curl -s http://127.0.0.1:8080/healthz
```

Важно: для systemd источник правды — **`/etc/suggest-bridge/env`**. Переменные из EnvironmentFile уже в окружении; project `.env` их не перезапишет. Unit по умолчанию без `User=` (часто root) — см. [[Деплой]].

## После первого запуска

1. Discord: после старта бота slash появляются на сервере сразу (если список пуст — перезапустите клиент), затем `/setup_suggest`, при необходимости `/decorate_server` — [[Discord]].
2. Telegram: `/start` в личку — [[Telegram]].
3. Модерация и команды — [[Модерация]], [[Команды]].

Если не стартует — [[Устранение-неисправностей]].
