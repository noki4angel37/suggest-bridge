# Безопасность

Официальная политика: [SECURITY.md](https://github.com/noki4angel37/suggest-bridge/blob/main/SECURITY.md).

**Не** открывайте публичные Issues для уязвимостей — только [GitHub Security Advisories](https://github.com/noki4angel37/suggest-bridge/security/advisories/new). Срок ответа ориентир — 7 дней.

## Секреты

- Никогда не коммитьте `.env`, `local.env`, `/etc/suggest-bridge/env`, живую `bridge.db`.
- В wiki и тикетах — только плейсхолдеры (`REPLACE_ME`), без реальных токенов.
- Утечка: rotate `BOT_TOKEN` (@BotFather) и `DISCORD_TOKEN` (Developer Portal); смените `HOST_SYNC_SECRET` на **всех** ПК; проверьте старые zip/бэкапы.

## Trust boundaries

| Зона | Риск |
|------|------|
| Хост с `.env` + токены | Полный контроль бота и публикации |
| Syncthing device с write на `HOST_SYNC_DIR` | **Высокий trust**: целостность sync-плоскости, handover, registry. HMAC блокирует **подделку** подписанных messages без секрета — это не повод шарить папку с незнакомцами |
| Discord mod role (не admin бота) | Модерация заявок; **не** `/host` |
| Админ бота | Админ-команды, block, настройки, host |

Правила Multi-PC: только доверенные Syncthing-устройства; не кладите `.env`/БД в sync-папку; при компрометации пира — rotate секрета на всех ПК.

## Health-порт

Процесс слушает **`0.0.0.0:HEALTH_PORT`**. Примеры `curl 127.0.0.1` не означают, что порт закрыт снаружи.

- Docker: предпочитайте publish `127.0.0.1:8080:8080` или не публикуйте порт и проверяйте health изнутри сети.
- VPS: firewall deny на 8080 из интернета, либо оставьте `HEALTH_PORT` пустым, если мониторинг не нужен.
- Не открывайте health в публичный интернет без нужды.

Invite permissions = **268561488** (включает Manage Messages и Manage Roles для setup). **Никогда Administrator** «на всякий случай». Разбор битов: [[Discord]].

## Меры в коде (ветка main)

| Область | Мера |
|---------|------|
| `/host` Discord | Только админы бота; модераторы — read-only sticky |
| Host-sync | HMAC + replay window на commands/acks/registry |
| Downloads | Allowlist CDN/TG; без произвольных redirects; private IP blocked |
| Moderation | CAS на смену статуса заявки |
| Decorate | Owner + invoker не блокируются overwrite |
| Docker | Non-root user |
