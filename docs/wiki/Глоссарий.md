# Глоссарий

| Термин | Значение |
|--------|----------|
| **Платформа / Suggest Bridge** | Открытое ядро Telegram ↔ Discord. Свои функции пишете локально через `SB_MODULES`; в этот GitHub они не попадают. В комплекте — примеры (предложка, мост, модерация и др.) |
| **Модуль** | Встроенная или сторонняя (`SB_MODULES`) функция на общем ядре |
| **Предложка** | Модуль: поток заявок от участников → модерация → публикация |
| **Primary** | ПК/процесс, держащий Telegram long polling и host lease |
| **Standby** | Процесс в ожидании `go_primary` |
| **Lease** | Запись в БД «кто сейчас primary» + TTL/heartbeat |
| **Host-sync** | Обмен командами через файлы в `HOST_SYNC_DIR` (Syncthing) + HMAC |
| **Агент** | Windows-процесс `bot.agent` / `run-agent.ps1`, поднимает primary по команде |
| **PublishRouter** | Сервис публикации в TG и/или Discord с rollback |
| **Mirror / зеркало** | Копирование постов ленты TG ↔ Discord (не модерационных публикаций) |
| **Mirror stub** | Запись-маркер, чтобы модерационный пост не задвоился зеркалом |
| **CAS** | Compare-and-swap статуса заявки (идемпотентный approve/reject) |
| **MemoryStorage** | FSM aiogram в RAM; не переживает рестарт |
| **Dual-publish** | Публикация одной заявки в TG и Discord |
| **Guild** | Discord-сервер |
| **Админ бота** | Запись в таблице админов (TG/DS), не путать с ролью модератора канала |
| **Модератор канала** | Discord-роль для карточек; без прав `/host` |
| **healthz** | HTTP-проверка готовности процесса |
| **bridge.db** | SQLite база моста |
| **Проходка** | Временная Discord-роль; `/prohodka` + закрытые каналы через `/setup_pass` |
| **268561488** | Integer Discord OAuth2 permissions для invite (Manage Messages + Manage Roles; не Administrator). Старое **126032** без Manage Roles недостаточно для setup |
