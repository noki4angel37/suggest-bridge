# Команды

Справочник по коду (`bot/adapters/…`). Меню BotFather показывает только часть Telegram-команд.

## Telegram — пользователь

| Команда | Кто | Описание |
|---------|-----|----------|
| `/start` | все | Сброс FSM, интро предложки |
| `/cancel` | все | Отмена шага черновика |
| текст / медиа | все | Черновик → модерация |

## Telegram — админ (личка)

Фильтр: private chat + админ бота.

| Команда | Алиасы | Описание |
|---------|--------|----------|
| `/adminhelp` | `/adminsettings` | Справка админа |
| `/queue` | — | Очередь модерации и отложенные публикации |
| `/download` | `/getbot`, `/install_pc` | Инструкция + zip агента (без секретов) |
| `/admins` | — | Список админов TG + DS |
| `/addadmin` | — | Выдать TG-админа: `/addadmin <@username\|id>` |
| `/deladmin` | — | Снять TG-админа |
| `/adddiscordadmin` | — | Выдать DS-админа (числовой id) |
| `/deldiscordadmin` | — | Снять DS-админа |
| `/blocked` | — | Чёрный список |
| `/block` | — | `/block <tg\|ds> <id> [причина]` |
| `/unblock` | — | `/unblock <tg\|ds> <id>` |
| `/antiflood` | — | Показать; `/antiflood set <limit> <seconds>` |
| `/ratelimit` | — | Пояснение про per-guild лимит Discord |
| `/host` | — | Панель multi-PC |
| `/host_consent` | — | Согласие этого ПК на primary lease |
| `/host_release` | — | Отозвать согласие + снять lease |
| `/host_status` | — | Статус lease / heartbeat / consent |
| `/mirror` | — | Статус; `/mirror on\|off` (также `1/0`, `вкл/выкл`, `enable/disable`) |
| `/repost` | — | Ручное зеркало TG→DS: `/repost <tg_message_id>` |
| `/cancel` | — | Отмена FSM ответа/отклонения (TTL 15 мин) |

Меню `set_my_commands`: `start`, `host`, `download`, `adminhelp`, `host_status`, `mirror`.

## Discord — пользователь

| Команда | Описание |
|---------|----------|
| `/suggest` | Отправить заявку (ephemeral) |
| `/prohodka` | Запросить временную роль проходки (локализованное имя по умолчанию «проходка») |
| сообщение в канале заявок | Ingest → удаление → черновик в ЛС |

## Discord — настройка сервера

| Команда | Права | Описание |
|---------|-------|----------|
| `/setup_suggest` | manage_guild + may_setup | Каналы и роли предложки |
| `/setup_info` | manage_guild + may_setup | Текущие настройки |
| `/setup_pass` | manage_guild + may_setup | Роль проходки и закрытые каналы; можно вызывать снова |
| `/decorate_server` | manage_guild + may_setup | Категории, имена, ACL |

## Discord — админ бота

| Команда | Описание |
|---------|----------|
| `/admins_list` | Список админов TG + DS |
| `/queue` | Очередь и отложенные |
| `/download_bot` | Zip + инструкция в ЛС |
| `/admin_add` | Выдать админа (`platform`, `user` / `user_id`) |
| `/admin_remove` | Снять админа |
| `/block_user` | Блок (`platform`, `user_id`, `reason?`) |
| `/unblock_user` | Разблок |
| `/blocked_list` | Чёрный список |
| `/roles_propose` | Роли, кто может предлагать (пусто = все); guild_only + manage_guild |
| `/roles_mod` | Роли модерации; guild_only + manage_guild |
| `/antiflood_config` | Глобальный антифлуд (`limit`, `window_sec`) |
| `/ratelimit_config` | Лимит этого сервера (`enabled`, `count`, `window_sec`); guild_only + manage_guild |

## Discord — multi-PC

| Команда | Описание |
|---------|----------|
| `/host` | Панель primary / передача (только админы бота; ephemeral) |
| `/host_accept` | Принять запрос (`request_id`) |
| `/host_reject` | Отклонить |
| `/host_cancel` | Отменить свой запрос |

Модерация заявок идёт **кнопками на карточках**, не отдельными slash-командами — см. [[Модерация]].

Временный доступ к закрытым каналам: [[Проходка]] (`/prohodka`, `/setup_pass`).

Почему список `/` пустой или отстаёт: [[Слэш-команды-Discord]].
