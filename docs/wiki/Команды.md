# Команды

Справочник по коду (`bot/adapters/…`). Меню BotFather показывает только часть Telegram-команд. В Discord часть имён в русском клиенте локализована (`locale_str`).

> **`/adminhelp` есть только в Telegram.** В Discord такой slash-команды нет — справка здесь и на связанных страницах вики.

## Частые ошибки (TG ≠ Discord)

| Искали в Discord | Правильно |
|------------------|-----------|
| `/adminhelp` | Нет в Discord. В Telegram: `/adminhelp`. Справка: эта страница |
| `/admins` | Discord: `/admins_list` · Telegram: `/admins` |
| `/addadmin` / `/deladmin` | Discord: `/admin_add` / `/admin_remove` · Telegram: `/addadmin` / `/deladmin` |
| `/download` | Discord: `/download_bot` · Telegram: `/download` |
| `/block` / `/blocked` | Discord: `/block_user` / `/blocked_list` · Telegram: `/block` / `/blocked` |
| `/antiflood` | Discord: `/antiflood_config` · Telegram: `/antiflood` |

## Telegram — пользователь

| Команда | Кто | Описание |
|---------|-----|----------|
| `/start` | все | Сброс FSM, интро предложки |
| `/cancel` | все | Отмена шага черновика |
| текст / медиа | все | Черновик → модерация |

## Telegram — админ (личка)

Фильтр: private chat + админ бота. **Только Telegram** — эти имена в Discord не работают.

| Команда | Алиасы | Описание |
|---------|--------|----------|
| `/adminhelp` | `/adminsettings` | Справка админа (**только TG**) |
| `/queue` | — | Очередь модерации и отложенные публикации |
| `/download` | `/getbot`, `/install_pc` | Инструкция + zip агента (без секретов) |
| `/admins` | — | Список админов TG + DS |
| `/addadmin` | — | Выдать TG-админа: `/addadmin <@username\|id>` |
| `/deladmin` | — | Снять TG-админа |
| `/adddiscordadmin` | — | Выдать DS-админа (числовой id) |
| `/deldiscordadmin` | — | Снять DS-админа |
| `/blocked` | — | Чёрный список |
| `/block` | — | `/block <tg\|ds> <id> [причина]` |
| `/unblock` | — | `/unblock <tg\|ds> <id>` |
| `/antiflood` | — | Показать; `/antiflood set <limit> <seconds>` |
| `/ratelimit` | — | Пояснение про per-guild лимит Discord |
| `/host` | — | Панель multi-PC |
| `/host_consent` | — | Согласие этого ПК на primary lease |
| `/host_release` | — | Отозвать согласие + снять lease |
| `/host_status` | — | Статус lease / heartbeat / consent |
| `/mirror` | — | Статус; `/mirror on\|off` (также `1/0`, `вкл/выкл`, `enable/disable`) |
| `/repost` | — | Ручное зеркало TG→DS: `/repost <tg_message_id>` |
| `/cancel` | — | Отмена FSM ответа/отклонения (TTL 15 мин) |

Меню `set_my_commands`: `start`, `host`, `download`, `adminhelp`, `host_status`, `mirror`.

## Discord — multi-PC

| API-имя | В RU-клиенте | Описание |
|---------|--------------|----------|
| `/host` | `/host` | Панель primary / передача (админы бота или админ-роли гильдии; ephemeral) |
| `/host_accept` | `/host_accept` | Принять запрос (`request_id`) |
| `/host_reject` | `/host_reject` | Отклонить |
| `/host_cancel` | `/host_cancel` | Отменить свой запрос |

Модерация заявок идёт **кнопками на карточках**, не отдельными slash-командами — см. [[Модерация]].

Временный доступ к каналам с проходкой: [[Проходка]] (`/prohodka` / `/проходка`, `/setup_pass` / `/настроить_проходку`, `/pass_config` / `/срок_проходки`). Админ-роли сервера: `/admin_roles`.

Почему список `/` пустой или отстаёт: [[Слэш-команды-Discord]].
