На этой странице — **текстовые моки** того, как выглядят основные экраны Suggest Bridge. Это **не скриншоты** из живого сообщества: имена, номера заявок и тексты вымышлены.

## Черновик перед отправкой (Telegram)

После текста или медиа бот показывает черновик и кнопки. Аналогичный сценарий есть в Discord через ЛС бота после `/suggest` или сообщения в канале заявок.

```
┌─────────────────────────────────────────────┐
│  📝 Черновик заявки                         │
│                                             │
│  Предложить добавить FAQ по установке       │
│  Docker для новичков.                       │
│                                             │
│  Режим: 👤 С именем                         │
│                                             │
│  [ ✏️ Изменить текст ]                      │
│  [ 👤 С именем ] [ 🕶 Анонимно ]           │
│  [ ✅ Отправить на модерацию ]              │
│  [ ❌ Отменить ]                            │
└─────────────────────────────────────────────┘
```

| Кнопка | Действие |
|--------|----------|
| **Изменить текст** | Вернуться к редактированию (до 400 символов) |
| **С именем / Анонимно** | Как будет подпись в опубликованном посте |
| **Отправить на модерацию** | Заявка уходит в очередь; черновик закрывается |
| **Отменить** | Черновик удаляется, заявка не создаётся |

> Черновик в Telegram **не сохраняется** при перезапуске бота — если бот «молчит», начните с `/start`. Подробнее: [[Как-отправить-заявку]].

### Поток кнопок (кратко)

```
Текст или медиа
      ↓
  Черновик
      ↓
┌─────┴─────┐
│ Изменить? │──→ снова текст
└─────┬─────┘
      ↓
 Аноним / с именем
      ↓
 Отправить? ──→ очередь модерации
      │
   Отменить ──→ конец
```

## Карточка модерации

Модераторы видят такую карточку в Telegram или Discord (одна заявка — одна очередь на обе платформы).

```
┌─────────────────────────────────────────────┐
│  ⏳ Заявка #42 · Discord                    │
│                                             │
│  Предложить добавить FAQ по установке       │
│  Docker для новичков.                       │
│                                             │
│  👤 Аноним                                  │
│  🗨 Discord                                  │
│                                             │
│  [ ✅ Одобрить ] [ ❌ Отклонить ]           │
│  [ ✉️ Ответить ] [ 🕒 Отложить ]            │
└─────────────────────────────────────────────┘
```

| Элемент | Смысл |
|---------|-------|
| **#42 · Discord** | Номер заявки и откуда пришла |
| **👤 Аноним** | Как автор хочет видеть подпись в канале |
| **🗨 Discord** | Платформа отправки |

Действия модератора — в [[Модерация]].

## Опубликованный пост

После одобрения пост появляется в Telegram-канале и/или в Discord `#предложка` (зависит от настроек администратора).

```
Предложить добавить FAQ по установке Docker для новичков.

👤 Аноним
🗨 Discord

#предложка
```

| Строка | Откуда |
|--------|--------|
| Основной текст | Текст заявки (до 400 символов) |
| **👤 Аноним** | Режим, выбранный автором в черновике |
| **🗨 Discord** | Источник заявки |
| **#предложка** | Хештег сообщества (имя настраивает админ) |

Если включено **зеркало ленты**, копия может появиться и на второй платформе — см. [[Модерация]].

## Статусы с точки зрения подписчика

| Статус | Что видите вы |
|--------|----------------|
| Черновик | Кнопки редактирования и отправки (см. выше) |
| На модерации | Подтверждение от бота; ждёте решения |
| Одобрено | Пост в канале / ленте |
| Отложено | Пост выйдет позже — время задаёт модератор |
| Отклонено | Сообщение в личку, иногда с причиной |
