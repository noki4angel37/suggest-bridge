# Антифлуд и блокировки

Ограничения на **отправку заявок** подписчиками. При срабатывании лимита или блокировки автор получает **отказ на submit** — заявка **не попадает** в очередь модерации.

Команды: [[Команды]]. Вопросы подписчиков «почему не отправляется»: [[FAQ-подписчиков]].

## Антифлуд (глобальный)

Считает заявки **на пользователя** в скользящем окне. Счётчики хранятся в SQLite с `BEGIN IMMEDIATE`.

| Параметр | По умолчанию |
|----------|--------------|
| Лимит | **5** заявок |
| Окно | **60** секунд |

### Настройка

| Команда | Платформа | Описание |
|---------|-----------|----------|
| `/antiflood` | Telegram | Показать текущие значения |
| `/antiflood set <limit> <seconds>` | Telegram | Изменить глобальный лимит |
| `/antiflood_config` | Discord | Глобальный антифлуд (`limit`, `window_sec`) |
| `/ratelimit` | Telegram | Пояснение про per-guild лимит Discord |

Типичная стратегия: начать с небольшого `limit` и окна в минуты, подстроить под активность сообщества. Текущие значения всегда видны командами **без аргументов**.

## Per-guild лимит (Discord)

Отдельный лимит **на сервер Discord**. По умолчанию **выключен**; при включении **перекрывает** глобальные числа для заявок с этого guild.

| Команда | Права | Параметры |
|---------|-------|-----------|
| `/ratelimit_config` | manage_guild + may_setup, guild_only | `enabled`, `count`, `window_sec` |

## Что видит автор при отказе

При превышении антифлуда подписчик получает сообщение с указанием лимита и окна (формат зависит от платформы). Заявка **не создаётся** — модераторы её не увидят.

Дополнительные ограничения на submit (не антифлуд, но тоже отказ):

- чёрный список (`/block`, `/block_user`);
- отсутствие роли «кто может предлагать» (если настроено через `/roles_propose`);
- лимит текста **400** символов.

## Блокировки

Ручной запрет конкретному пользователю.

| Команда | Платформа | Синтаксис |
|---------|-----------|-----------|
| `/block` | Telegram | `/block <tg\|ds> <id> [причина]` |
| `/unblock` | Telegram | `/unblock <tg\|ds> <id>` |
| `/blocked` | Telegram | Список заблокированных |
| `/block_user` | Discord | `platform`, `user_id`, `reason?` |
| `/unblock_user` | Discord | `platform`, `user_id` |
| `/blocked_list` | Discord | Список |

Заблокированный автор получает отказ при попытке отправить заявку.

## Сводка для оператора

```
Глобальный антифлуд (TG + DS)     → /antiflood, /antiflood_config
Лимит только этого Discord-сервера → /ratelimit_config
Запрет конкретному человеку        → /block, /block_user
```
