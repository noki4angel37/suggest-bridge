# Требования к хосту

Где и на каком железе держать Suggest Bridge. Один инстанс рассчитан на **одно сообщество** (1 TG-канал + 1 DS guild).

Деплой: [[Деплой]]. Несколько ПК админов: [[Multi-PC]].

## Минимальные требования

Проект **не публикует** жёсткий SLA по железу. Практический ориентир для одного сообщества:

| Ресурс | Ориентир |
|--------|----------|
| Python | **3.11+** |
| RAM | **512 MB** и выше (1 GB комфортнее с Docker и медиа-кэшем) |
| CPU | 1 vCPU достаточно; нагрузка низкая между пиками заявок |
| Диск | Локальный SSD/HDD; SQLite `bridge.db` + опционально `data/media/` |
| Сеть | Исходящий HTTPS к API Telegram и Discord |

Бот **не** требует GPU и не держит тяжёлых фоновых job, кроме планировщика отложенных публикаций (~30 с poll).

## Always-on

Telegram работает через **long polling** — процесс **primary** должен быть **постоянно запущен**. Краткие рестарты допустимы; длительный downtime = бот «молчит», отложенные публикации ждут в SQLite.

| Сценарий | Подходит? |
|----------|-----------|
| Домашний ПК / мини-ПК 24/7 | Да |
| Linux VPS | Да, частый выбор |
| Ноутбук «когда включён» | Плохо для prod; возможны пропуски polling |
| Serverless / cron раз в час | **Нет** |

Health-check (опционально): `GET /healthz` при заданном `HEALTH_PORT` — [[Деплой]].

## Варианты развёртывания

| Вариант | Когда выбирать |
|---------|----------------|
| **Docker** (Linux / VPS) | Рекомендуется для сервера: изоляция, `restart: unless-stopped`, volume `./data` |
| **systemd** | VPS без Docker; unit из `contrib/systemd/` |
| **Windows**, один ПК | `python -m bot.main` или zip из Releases; автозапуск вручную |
| **Windows + агент** | Несколько админов — [[Multi-PC]] |

Docker-образ работает от non-root user `suggest` — на Linux выдайте права на volume `./data` (см. [[Деплой]]).

## SQLite и диск

- База: `bridge.db` (`BRIDGE_DB_PATH`), режим WAL.
- **Не** кладите БД на сетевой диск с плохой file locking — риск `database is locked`.
- Бэкап: `bridge.db` + `-wal` + `-shm` одной эпохи — [[Эксплуатация]].
- Медиа-кэш (`data/media/`) растёт с вложениями; бэкапьте отдельно при необходимости.

## Multi-PC (опционально)

Если primary крутится на Windows у одного админа, а другие ПК только передают lease:

- Syncthing на **`HOST_SYNC_DIR`** (не `.env`, не `bridge.db`).
- Один `HOST_SYNC_SECRET` на все доверенные ПК.
- Агент — только Windows; модерация из Telegram/Discord приложений возможна с любого устройства.

Подробнее: [[Multi-PC]], [[Безопасность]].

## Один инстанс — одно сообщество

Код может видеть несколько Discord guild, но **основной сценарий** — одно сообщество на процесс. Не шарите один `BOT_TOKEN` между независимыми инстансами.

## VPS vs домашний ПК

| | VPS | Домашний ПК |
|---|-----|-------------|
| Uptime | Стабильнее | Зависит от электричества и сна |
| Стоимость | Ежемесячная | Уже есть железо |
| Безопасность | Закройте `HEALTH_PORT` снаружи — [[Безопасность]] | Токены на домашней машине — доверенная зона |

VPS **не обязателен** — см. [[FAQ]].
