# Telegram

## Подготовка бота и канала

1. [@BotFather](https://t.me/BotFather) → `/newbot` → сохраните `BOT_TOKEN` в `.env` (не в git).
2. Создайте канал публикации. Добавьте бота **администратором** с правом публиковать сообщения.
3. Узнайте `CHANNEL_ID` в формате `-100…` (@RawDataBot, веб-клиент, или API `getChat`).
4. `ADMIN_IDS` — ваш числовой user id (Settings → Advanced → Developer mode → Copy User ID). Несколько админов — через запятую.
5. Опционально: `OWNER_TELEGRAM_ID` (иначе супер-админ = первый из `ADMIN_IDS`).

После старта бот обновляет меню команд (`set_my_commands`): `/start`, `/host`, `/download`, `/adminhelp`, `/host_status`, `/mirror`. Остальные админ-команды работают, но не все в меню — полный список: [[Команды]].

> `/adminhelp` и остальные имена из этого раздела — **только Telegram**. В Discord их нет (там другие slash-имена: `/admins_list`, `/admin_add`, …).

## Путь автора

1. Личка боту: текст (≤ **400** символов), фото, видео, стикер, ссылка, альбом.
2. Черновик с кнопками: изменить текст, анонимно / с именем, отправить на модерацию, отменить.
3. Заявка попадает в общую очередь; карточка модерации — у админов в личке (и в Discord, если режим `both`).

Ограничения: чёрный список, антифлуд (глобальные лимиты), лимит текста 400.

## Команды пользователя

| Команда | Описание |
|---------|----------|
| `/start` | Сброс FSM, интро предложки |
| `/cancel` | Отмена текущего шага черновика |
| Текст / медиа | Создать или дополнить черновик |

## Админ (личка, только Telegram)

| Команда | Описание |
|---------|----------|
| `/adminhelp` | Справка (**нет в Discord**) |
| `/queue` | Очередь и отложенные |
| `/host` | Multi-PC панель |
| `/download` | Zip + инструкция агента (в Discord: `/download_bot`) |
| `/mirror on\|off` | Включить/выключить зеркало ленты |
| `/cancel` | Отмена FSM ответа/отклонения |

Полный справочник (включая `/addadmin`, `/block`, `/repost`, …): [[Команды]].

## Важные ограничения

- **MemoryStorage** — черновики и FSM ответа не переживают рестарт процесса.
- FSM ответа/причины отклонения: TTL **15 минут**.
- Оригинал поста в канале Telegram бот **не редактирует** при правках зеркала с Discord (правки/удаления касаются копий с origin Discord, где применимо).
- Заявки из Telegram **не** зеркалятся карточками в Discord автоматически в мульти-guild сценарии (нужен однозначный guild). Обратное направление (Discord → карточки TG-админам) работает в режиме `both`.
