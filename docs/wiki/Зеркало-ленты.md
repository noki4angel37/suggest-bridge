# Зеркало ленты

**Зеркало** — автоматическая синхронизация **обычных постов** между Telegram-каналом публикации и Discord-лентой `#предложка`. Это **не** то же самое, что публикация одобренной заявки из модерации.

Подробнее о модерации и публикации заявок: [[Модерация]]. Команды: [[Команды]].

## Что синхронизируется

| Направление | Поведение |
|-------------|-----------|
| Telegram → Discord | Пост в TG-канале копируется в Discord `#предложка` |
| Discord → Telegram | Пост в Discord-ленте копируется в TG-канал |

- Дедупликация через таблицу `mirror_links` в SQLite — повторов быть не должно.
- **Голосовые** и **video note** не переносятся.
- Длинный текст **обрезается**: Discord — **2000** символов, подпись Telegram — **1024**.

## Чем зеркало отличается от модерации

| | Зеркало ленты | Публикация из модерации |
|---|---------------|-------------------------|
| Источник | Обычный пост админа в канале/ленте | Одобренная заявка подписчика |
| Очередь модерации | Нет | Да |
| Дублирование | Копия на вторую платформу | `PublishRouter` по `publish_target` |

Публикации из модерации **не** дублируются зеркалом повторно: перед Discord-стороной пишется **mirror stub** (`kind=suggest_publish`), чтобы пост не появился в ленте дважды. При ошибке dual-publish stubs очищаются вместе с rollback — см. [[Модерация]].

## Управление

По умолчанию зеркало **включено** (`mirror_enabled` в settings БД).

| Команда | Где | Описание |
|---------|-----|----------|
| `/mirror` | Telegram (личка, админ) | Текущий статус |
| `/mirror on` | Telegram | Включить |
| `/mirror off` | Telegram | Выключить |
| `/repost <tg_message_id>` | Telegram | Ручное зеркало TG→DS после сбоя |

Алиасы для on/off: `1/0`, `вкл/выкл`, `enable/disable`.

`/mirror` есть в меню BotFather; полный список админ-команд — [[Команды]].

## Когда использовать `/repost`

Если зеркало было выключено, primary менялся или пост в TG-канале не дошёл до Discord — админ Telegram может вручную отправить копию:

```
/repost 12345
```

где `12345` — id сообщения в TG-канале (не id заявки модерации).

## Типичные проблемы

| Симптом | Что проверить |
|---------|---------------|
| Зеркало молчит | `/mirror` — enabled? Права бота в обоих каналах |
| Дубли в Discord | Два процесса с одним `BOT_TOKEN`; обновите код (stubs на актуальном `main`) |
| Обрезанный текст | Лимиты 2000 / 1024 — ожидаемо |

Runbook: [[Устранение-неисправностей]] (разделы «зеркало молчит», «дубли в Discord»).
