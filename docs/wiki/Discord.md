# Discord

## Developer Portal (разово)

1. [Discord Developer Portal](https://discord.com/developers/applications) → **New Application** → вкладка **Bot** → Reset Token → значение в `DISCORD_TOKEN`.
2. **Privileged Gateway Intents**:
   - **Message Content Intent** — чтение канала заявок (бот видит текст в каналах, куда есть доступ — ограничивайте ACL каналов);
   - **Server Members Intent** — проверка ролей.
3. **OAuth2 → URL Generator**:
   - scopes: `bot` + `applications.commands`;
   - permissions integer: **268561488** (не Administrator).
4. Пригласите бота на сервер по сгенерированной ссылке.
5. В `.env`: `OWNER_DISCORD_ID` — ваш числовой Discord user id:
   - Discord → Settings → Advanced → **Developer Mode** → ПКМ по своему аватару → **Copy User ID**.
   - Обязателен в режиме **discord_only**; в режиме **both** — рекомендуется (bootstrap админа бота / `/host`).

### Что входит в 268561488

Сумма битов (не «включите всё» и **не** Administrator):

| Право | Бит | Зачем |
|-------|-----|--------|
| Manage Channels | 16 | `/setup_suggest`, `/decorate_server`, `/setup_pass` |
| Add Reactions | 64 | карточки / UX |
| View Channel | 1024 | чтение каналов |
| Send Messages | 2048 | публикация и ответы |
| **Manage Messages** | 8192 | удаление заявок из канала после ingest |
| Embed Links | 16384 | эмбеды карточек |
| Attach Files | 32768 | медиа |
| Read Message History | 65536 | история |
| **Manage Roles** | 268435456 | `create_role` (например `недоадмин`) в setup/decorate |

Старое значение **126032** (без Manage Roles) **недостаточно** для `/setup_suggest` / `/decorate_server` на чистом сервере — получите `Forbidden` на создании роли.

Slash-команды: глобальный `tree.sync()`, guild-копии при старте очищаются (иначе в `/` дубли). Подробнее: [[Слэш-команды-Discord]]. Если пикер пустой или кэш старый — полностью выйдите из Discord и откройте снова.

## Настройка на сервере

1. **`/setup_suggest`** — каналы заявок / модерации / публикации и роли (имена из `.env`, см. [[Конфигурация]]). Параметры: `канал_заявок`, `канал_модерации`, `канал_публикации`, `роль_для_заявок`, `роль_модерации`. Нужны права setup (админ бота или guild admin с manage_guild).
2. **`/decorate_server`** — категории, emoji┃имена, ACL ленты. Owner и **invoker** получают break-glass overwrite — invoker должен быть доверенным лицом.
3. **`/setup_info`** — проверить текущие настройки (тоже manage_guild + may_setup).
4. **`/setup_pass`** (опционально) — роль проходки и закрытые каналы. Повторный вызов с другим именем добавляет ещё канал. Подробности: [[Проходка]].

Если setup уже частично создал каналы: повторный `/setup_suggest` с явными параметрами каналов привяжет существующие; при сбое overwrite — проверьте иерархию ролей бота (роль бота выше создаваемых).

Типичные имена по умолчанию: категория `ПРЕДЛОЖКИ`, каналы `посты-предложения`, `модерация-предложки`, `предложка`, роль редактора `недоадмин`.

## Кто что может (ACL)

| Роль | Заявки | Карточки модерации | `/host`, админ-команды бота |
|------|--------|--------------------|------------------------------|
| Участник (+ роль предложки, если задана) | да | нет | нет |
| Модератор канала / роль модерации | — | да | нет |
| Админ бота (`OWNER_DISCORD_ID` / `admin_add`) | — | да | да |
| Guild admin (Manage Guild) | setup/decorate | по ролям | не автоматически admin бота |

## Путь автора

| Способ | Поведение |
|--------|-----------|
| Сообщение в `#посты-предложения` | Сообщение удаляется, черновик в ЛС |
| `/suggest` | Ephemeral диалог заявки |

Ограничения: чёрный список, антифлуд / per-guild rate limit, лимит 400 символов, опционально роль «кто может предлагать».
