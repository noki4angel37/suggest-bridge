# Проходка

Дата: 2026-08-26

Временная роль Discord: участник запрашивает доступ, модератор предложки принимает или отклоняет заявку, роль открывает закрытые каналы на ограниченное время.

Это **не** тема сервера и не набор мини-игр. Админ сам решает, какие каналы закрыть ролью.

## Что сделано

- `/prohodka` (в русском клиенте — локализованное имя, по умолчанию «проходка») — заявка на временную роль.
- `/setup_pass` — создать роль (если её нет), закрыть существующий канал или создать новый. Повторный вызов с другим именем добавляет ещё один канал за той же ролью.
- Карточка заявки приходит в канал модерации предложки (те же модераторы, что разбирают посты). Кнопки «Принять» / «Отклонить».
- После истечения срока роль снимается. Отклонённую заявку нельзя сразу повторить (пауза по умолчанию 5 минут). Есть антиспам по частым вызовам команды.

## Как устроено

1. Админ вызывает `/setup_pass` на сервере (нужны Manage Guild и права setup, как у `/setup_suggest`).
2. Бот находит или создаёт роль проходки, сохраняет её id для этой гильдии, применяет ACL: `@everyone` не видит канал, роль проходки и бот видят и пишут.
3. Участник вызывает `/prohodka` с любого канала сервера.
4. Модератор принимает заявку → бот выдаёт роль на срок из `.env` (по умолчанию 5 часов).
5. Фоновый цикл снимает роль, когда срок вышел.

Id роли можно задать заранее через `DISCORD_PASS_ROLE_ID`. Если вызывали `/setup_pass`, сохранённая для сервера роль **важнее** переменной окружения.

Карточки не уходят в Telegram: это Discord-роль и Discord-каналы.

## Как проверить

1. Бот запущен с `DISCORD_TOKEN`, на сервере уже есть `/setup_suggest` (нужен канал модерации для карточек).
2. Админ: `/setup_pass` без параметров — должны появиться категория «закрытые каналы» (если её не было) и канал «проходка».
3. Повторить `/setup_pass имя:чат` — второй закрытый канал за той же ролью.
4. Участник: `/prohodka` → ephemeral «заявка отправлена».
5. В канале модерации предложки — карточка. «Принять» → у участника роль, канал виден. «Отклонить» → пауза перед новой заявкой.
6. Роль бота в списке ролей сервера **выше** роли проходки, иначе выдача не сработает.

```text
pytest tests/test_pass_service.py tests/test_pass_rooms.py -q
```

## Команды

| Команда | Кто | Описание |
|---------|-----|----------|
| `/prohodka` | участник сервера | Запросить временную роль |
| `/setup_pass` | manage_guild + may_setup | Роль + закрытый канал; можно вызывать снова |

Параметры `/setup_pass`:

| Параметр | Назначение |
|----------|------------|
| `канал` | Существующий текстовый канал: только закрыть ACL |
| `имя` | Имя **нового** канала, если `канал` не указан |
| `категория` | Куда положить новый канал |
| `роль` | Готовая роль проходки; иначе бот найдёт по имени или создаст |

## Переменные `.env` (все опциональны)

| Переменная | Default | Назначение |
|------------|---------|------------|
| `DISCORD_PASS_ROLE_ID` | — | Готовая роль, если `/setup_pass` ещё не вызывали |
| `DISCORD_PASS_COMMAND` | `проходка` | Русское имя в пикере `/` |
| `DISCORD_PASS_LABEL` | `проходка` | Текст на карточке и в сообщениях |
| `DISCORD_PASS_ROLE_NAME` | как `LABEL` | Имя создаваемой роли |
| `DISCORD_PASS_CHANNEL_NAME` | `проходка` | Имя канала, если `/setup_pass` без параметров |
| `DISCORD_PASS_CATEGORY_NAME` | `закрытые каналы` | Категория для новых комнат |
| `DISCORD_PASS_DURATION_SEC` | `18000` (5 ч) | Сколько держится роль |
| `DISCORD_PASS_REJECT_COOLDOWN_SEC` | `300` | Пауза после отклонения |
| `DISCORD_PASS_ANTISPAM_LIMIT` | `5` | Попыток в окне до временного бана команды |
| `DISCORD_PASS_ANTISPAM_WINDOW_SEC` | `600` | Окно антиспама |
| `DISCORD_PASS_ANTISPAM_STRIKE_SEC` | `900` | Длительность страйка |
| `DISCORD_PASS_DEBOUNCE_SEC` | `8` | Минимальный интервал между вызовами |
| `DISCORD_PASS_EXPIRY_POLL_SEC` | `30` | Как часто бот проверяет истечение |

## Ограничения

- Без канала модерации предложки карточка не отправится — сначала `/setup_suggest`.
- Существующую публичную категорию `/setup_pass` **не** переписывает целиком: ACL ставится на канал. Новая категория создаётся сразу закрытой.
- Пока роль выдана, повторный `/prohodka` недоступен.
- Чёрный список бота (`/block_user`) блокирует и проходку.
- Игры, войсы и оформление «под заведение» в этот модуль не входят.
