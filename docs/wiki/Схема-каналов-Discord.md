# Схема каналов Discord

Карта каналов и ролей, которые создаёт **`/setup_suggest`**, и оформление, которое добавляет **`/decorate_server`**. Команды и права бота — [[Discord]]; поток модерации — [[Модерация]].

Имена по умолчанию задаются переменными `SETUP_*` в `.env` (шаблон: [.env.example](https://github.com/noki4angel37/suggest-bridge/blob/main/.env.example), таблица — [[Конфигурация#Имена-каналов-(русские-defaults)]].

## Переменные имён (`SETUP_*`)

| Переменная | Default | Назначение |
|------------|---------|------------|
| `SETUP_CATEGORY_NAME` | `ПРЕДЛОЖКИ` | Категория для каналов предложки |
| `SETUP_SUGGEST_CHANNEL_NAME` | `посты-предложения` | Канал **приёма** заявок |
| `SETUP_MOD_CHANNEL_NAME` | `модерация-предложки` | Канал модераторов (опционально) |
| `SETUP_PUBLISH_CHANNEL_NAME` | `предложка` | **Лента** одобренных публикаций |
| `SETUP_PUBLISH_CHANNEL_ALIASES` | `посты-опубликованно` | Legacy-имя ленты (при rebind) |
| `SETUP_EDITOR_ROLE_NAME` | `недоадмин` | Роль редакторов ленты публикации |

Связанные (не `SETUP_*`, но в подписи постов): `SUGGEST_HASHTAG` (`#предложка`), `ANON_NAME` (`Аноним`).

## После `/setup_suggest`

Минимальная структура на сервере:

```
Discord Server
└── 📁 ПРЕДЛОЖКИ                    ← SETUP_CATEGORY_NAME
    ├── #посты-предложения            ← SETUP_SUGGEST_CHANNEL_NAME (inbox)
    ├── #модерация-предложки          ← SETUP_MOD_CHANNEL_NAME (staff)
    └── #предложка                    ← SETUP_PUBLISH_CHANNEL_NAME (feed)
```

Роль **`недоадмин`** (`SETUP_EDITOR_ROLE_NAME`) создаётся, если её ещё нет.

### Назначение каналов

| Канал | Кто пишет | Что происходит |
|-------|-----------|----------------|
| `#посты-предложения` | Участники (или только роль «кто может предлагать», если задана в `/setup_suggest`) | Сообщение **удаляется**, автор получает черновик в ЛС бота |
| `#модерация-предложки` | Роли модерации + бот | Служебный канал; карточки модерации приходят в ЛС и через UI бота |
| `#предложка` | Бот, роль `недоадмин`, owner guild, invoker decorate | **Лента** одобренных постов + зеркало из TG-канала |

Альтернатива inbox: slash **`/suggest`** (ephemeral) — канал заявок не обязателен для каждого автора.

## После `/decorate_server`

Та же логика каналов, но с emoji┃префиксами и раскладкой по категориям сообщества. Пример фрагмента категории предложки:

```
└── 📁 ПРЕДЛОЖКИ
    ├── 💡┃посты-предложения
    ├── 🛡️┃модерация-предложки
    └── 📨┃предложка
```

`/decorate_server` также может создать/переименовать другие категории и каналы (инфо, general, войсы и т.д.) — это **оформление**, не обязательное для работы очереди.

> **Break-glass:** owner guild и **invoker** `/decorate_server` получают полные overwrite на ленте — вызывайте команду только от доверенного лица.

## ACL: кто что видит и пишет

### `#посты-предложения` (inbox)

| Субъект | View | History | Send | Attach |
|---------|------|---------|------|--------|
| @everyone | ✅ | ❌ | ✅* | ✅* |
| Роль «кто может предлагать» (если задана) | ✅ | ❌ | ✅ | ✅ |
| Бот | ✅ | ✅ | ✅ | ✅ (+ Manage Messages) |

\* Если в `/setup_suggest` задана роль для заявок — писать могут **только** она (и бот); @everyone видит канал, но не шлёт сообщения.

История скрыта у участников намеренно: сообщения удаляются после ingest.

### `#модерация-предложки`

| Субъект | View | Send |
|---------|------|------|
| @everyone | ❌ | ❌ |
| Роли модерации (из setup) | ✅ | ✅ |
| Бот | ✅ | ✅ |

### `#предложка` (лента)

| Субъект | View | Send | Manage |
|---------|------|------|--------|
| @everyone | ✅ read | ❌ | ❌ |
| `недоадмин` | ✅ | ✅ | ✅ |
| Owner guild / invoker decorate | ✅ | ✅ | ✅ (break-glass) |
| Бот | ✅ | ✅ | ✅ |

Участники **читают** ленту, но не публикуют вручную — только модерация и редакторы.

### Роли и админ-команды бота

| Роль / статус | Inbox | Карточки модерации | `/host`, admin slash |
|---------------|-------|--------------------|----------------------|
| Участник (+ роль предложки, если есть) | submit | нет | нет |
| Модератор канала / роль модерации | — | да | нет |
| Админ бота (`OWNER_DISCORD_ID`, `admin_add`) | — | да | да |
| Guild admin (Manage Guild) | setup/decorate | по ролям | не автоматически admin бота |

## Порядок настройки

1. Invite бота с правами **268561488** (в т.ч. Manage Roles и Manage Messages) — [[Discord#Developer-Portal-(разово)]].
2. **`/setup_suggest`** — создать/привязать каналы и роли.
3. **`/setup_info`** — проверить id каналов в конфиге guild.
4. *(Опционально)* **`/decorate_server`** — визуал и ACL announce-каналов.

Повторный `/setup_suggest` с явными параметрами каналов привяжет **существующие** каналы. При `Forbidden` на создании роли — роль бота должна быть **выше** создаваемых ролей в иерархии Discord.

## Связь с Telegram (режим both)

| Поток | Discord-канал |
|-------|---------------|
| Заявка из Discord | inbox → модерация → `#предложка` |
| Заявка из Telegram | карточки DS-админам; публикация в `#предложка` по `publish_target` |
| Зеркало TG-канала | копии постов в `#предложка` (не дублирует модерационные публикации) |

Ограничение: заявки **только из Telegram** не зеркалятся карточками в Discord при нескольких guild на одном инстансе — см. [[Telegram#Важные-ограничения]], [[FAQ]].
