# Roadmap

Планы **Suggest Bridge** как **открытого ядра** Telegram ↔ Discord — без обещаний по срокам. Приоритеты могут сдвинуться по обратной связи и багам.

> Текущая версия и недавние изменения — [[Новости]] и [Releases](https://github.com/noki4angel37/suggest-bridge/releases).

## Готово (v0.1.0 и ранее)

| Область | Что есть |
|---------|----------|
| Заявки | Telegram ЛС, Discord `/suggest`, канал заявок |
| Модерация | Очередь, одобрение, отклонение, ответ автору, отложенная публикация |
| Публикация | Telegram-канал, Discord `#предложка`, dual-publish, зеркало ленты |
| Подписчик | Черновик, анонимность, лимит 400 символов, медиа |
| Админ | `.env`, Docker, systemd, Windows-агент, `/setup_suggest`, Multi-PC `/host` |
| Проходка | `/prohodka` (`/проходка`) + `/setup_pass` (`/настроить_проходку`) — в ветке `main` |
| Качество | CI с тестами, README RU/EN, SECURITY policy |
| Модули | Plugin API (`SB_MODULES`), пример `examples/sample_module` |
| Модерация (расширение) | Per-guild `/filter`, auto-reject/flag, страйки, `/warn`, `/case`, server `/automod`, report/unpublish |

## В работе

### Wiki и документация

- Перенос документации в GitHub Wiki (источник — `docs/wiki/` в репозитории).
- Страницы для **подписчиков**: правила, FAQ, примеры интерфейса, новости.
- Связка README ↔ Wiki ↔ Discord-сервер.

### Укрепление безопасности (unreleased)

- Строже доступ к Multi-PC: только доверенные админы бота управляют «хостом».
- Безопаснее скачивание вложений и меньше чувствительных данных в логах.
- Docker под непривилегированным пользователем; CI с проверкой зависимостей.

### Стабильность публикации

- Исправления гонок при dual-publish и зеркале ленты.
- Надёжнее отложенные публикации и повторная отправка в Discord после сбоя.

## Запланировано

Приоритет не фиксирован — список ориентировочный.

| Направление | Идеи |
|-------------|------|
| **Модули** | Документация локального `SB_MODULES` (свои функции не merge в этот репозиторий). Каталог community modules — возможное будущее сообщества, **не цель ядра** |
| **UX подписчика** | Понятнее сообщения бота при ошибках; подсказки в черновике |
| **UX модератора** | Больше контекста на карточке заявки без перегруза |
| **Документация** | Реальные скриншоты вместо текстовых моков ([[Примеры-интерфейса]]), больше сценариев в [[FAQ-подписчиков]] |
| **Эксплуатация** | Упрощение обновления на Windows и в Docker для малых сообществ |

Идеи и баги — [GitHub Issues](https://github.com/noki4angel37/suggest-bridge/issues). Обсуждение — [[Discord-сервер]].

## Вне scope (не планируем)

| Не делаем | Почему |
|-----------|--------|
| **Официальный marketplace модулей в этом репозитории** | Свои функции остаются на машине разработчика, не в официальный GitHub |
| **Отключение встроенных модулей через env** | Не цель ядра |
| **SaaS / облачный хостинг** | Проект — self-hosted: админ поднимает свой экземпляр |
| **Multi-tenant (много сообществ на одном инстансе)** | Один процесс = одно сообщество; проще безопасность и поддержка |
| **Замена модерации сообщества** | Бот не решает споры и не задаёт правила канала — это владельцы |
| **Официальная поддержка Telegram / Discord** | Это платформы; мы — мост между ними |
