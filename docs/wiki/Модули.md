# Модули

**Suggest Bridge** — модульная платформа: ядро `bot/core/` (БД, `EventBus`, сервисы) и адаптеры Telegram/Discord. Встроенные возможности — модули; свои подключаются через allowlist `SB_MODULES`.

## Встроенные модули (равный приоритет)

| Модуль | Документация | Кратко |
|--------|--------------|--------|
| **Предложка** | [[Как-отправить-заявку]], [[Модерация]] | Заявки → очередь → публикация |
| **Мост TG↔DS** | [[Зеркало-ленты]], [[Архитектура]] | Dual-publish, зеркало ленты |
| **Модерация** | [[Модерация]], [[Антифлуд-и-блокировки]] | Карточки, approve/reject, blocklist |
| **Проходка** | [[Проходка]] | Временная роль через модерацию |
| **Казино** | [[Команды]] | Мини-игры без валюты |
| **Multi-PC** | [[Multi-PC]] | `/host`, lease, Windows-агент |

Встроенные модули **не** отключаются через env в текущей версии — они часть composition root. Сторонние модули **дополняют** платформу, не заменяя встроенные.

## Подключение своих модулей (`SB_MODULES`)

Переменная окружения **`SB_MODULES`** — список через запятую или с новой строки. Каждая запись:

```text
package.module:ClassName
```

или путь к файлу:

```text
/path/to/my_module.py:MyModule
```

Пример (из репозитория, только для теста):

```env
SB_MODULES=examples/sample_module/module.py:SampleModule
```

После изменения `.env` перезапустите процесс бота.

| Правило | Зачем |
|---------|-------|
| Только явный allowlist | Нет автоскана site-packages |
| Ошибка одного модуля | Лог + остальные модули и встроенные фичи работают |
| Discord slash | Регистрируйте команды в `setup_discord` **до** sync (хук вызывается автоматически) |

Подробнее для авторов: [[Добавить-модуль]].

## API (кратко)

Класс модуля наследует `BaseBridgeModule` из `bot.core.modules`:

| Хук | Когда |
|-----|-------|
| `setup` | Общая инициализация |
| `setup_telegram` | Регистрация aiogram router |
| `setup_discord` | Cogs / `bot.tree.add_command` |
| `teardown` | Остановка процесса |

Контекст `ModuleContext`: `config`, `db`, `bus`, `services`, `telegram_bot`, `dp`, `discord_bot`, `discord_ctx`.

Пример: `examples/sample_module/` в репозитории.
