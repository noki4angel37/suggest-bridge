# Конфигурация

Конфиг: сначала уже заданные **переменные окружения**, затем файл `BOT_ENV_FILE` → `.env` → `local.env` в корне проекта. Уже экспортированные переменные **не** перезаписываются файлом.

- Локальный / Docker: обычно `.env` в корне (compose `env_file`).
- **systemd:** источник правды — **`/etc/suggest-bridge/env`** (`EnvironmentFile` в unit). Заполняйте его, а не только project `.env`.

`REPLACE_ME` в значении токенов/`ADMIN_IDS`/`CHANNEL_ID` ≡ «не задано» (код игнорирует как пустое). Для `HOST_SYNC_SECRET` и `OWNER_DISCORD_ID` **не** оставляйте литерал `REPLACE_ME` — либо реальный секрет/id, либо закомментируйте/очистите, если функция не нужна.

**Не коммитьте** `.env`, `local.env`, `/etc/suggest-bridge/env`, `data/bridge.db`.

Шаблон: [.env.example](https://github.com/noki4angel37/suggest-bridge/blob/main/.env.example).

Автоподготовка (создаёт `.env`, генерирует `HOST_SYNC_SECRET`, ставит `HEALTH_PORT=8080`):

```powershell
.\scripts\deploy\prepare-env.ps1
```

```bash
bash scripts/deploy/prepare-env.sh
```

## Обязательные (по режиму)

| Переменная | Режим | Описание |
|------------|-------|----------|
| `BOT_TOKEN` | TG / both | Token от @BotFather |
| `ADMIN_IDS` | TG / both | Telegram user id админов через запятую |
| `CHANNEL_ID` | TG / both | Id канала (`-100…`) |
| `DISCORD_TOKEN` | DS / both | Token бота Discord |
| `OWNER_DISCORD_ID` | **обязателен** в discord-only; в both — **рекомендуется** (bootstrap Discord-админа, force `/host`) | Супер-админ Discord (Developer Mode → Copy User ID) |

| Переменная | Default / пример | Описание |

| `OWNER_TELEGRAM_ID` | первый из `ADMIN_IDS` | Супер-админ TG |

## Модерация UX (опционально)

| Переменная | Описание |
|------------|----------|
| `ADMIN_CHAT_ID` | Telegram group/supergroup id: карточки модерации туда вместо ЛС админам |
| `KEYWORD_BLOCKLIST` | Подстроки через запятую; текст заявки с совпадением не попадает в очередь |
| `DISCORD_MOD_LOG_CHANNEL_ID` | Канал аудита approve/reject (`s{N}`, модератор, автор) |
| `DISCORD_PUBLISH_THREADS` | `1`/`true` — тред обсуждения под постом в `#предложка` |

На карточках показывается стабильный id **`s{N}`** (где N — id заявки в БД).

Зеркало ленты: правка TG↔DS и удаление DS→TG уже есть. Удаление поста в Telegram-канале Bot API обычно **не** доставляет боту — близнец в Discord остаётся (ограничение платформы, не баг).

## Безопасность конфига

- При утечке — rotate `BOT_TOKEN` и `DISCORD_TOKEN` в порталах; смените `HOST_SYNC_SECRET` на **всех** ПК.
- Syncthing-пиры с write на `HOST_SYNC_DIR` — **высокий trust** (целостность sync-плоскости). HMAC мешает **подделать** подписанные команды без секрета, но не делает безопасным шаринг папки с чужими устройствами. Не кладите `.env` / `bridge.db` в `HOST_SYNC_DIR`.
- `HOST_FORCE_CLAIM` — только для handover/аварии; после передачи уберите. На общих ПК предпочтите `HOST_REQUIRE_CONSENT=1`.
- Плейсхолдеры: `REPLACE_ME`, никогда реальные токены.
- Health: слушает `0.0.0.0`; не публикуйте порт в интернет без нужды — [[Безопасность]], [[Деплой]].
