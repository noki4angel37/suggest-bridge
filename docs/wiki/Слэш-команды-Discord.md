# Слэш-команды Discord

Дата: 2026-08-27

## Что сделано

Команды публикуются **только глобально** (`tree.sync()`). При старте на каждом сервере **очищается** guild-корзина slash (`clear_commands` + `sync(guild)`), чтобы в пикере `/` не было двух одинаковых строк (global + guild).

Раньше копирование на гильдию давало мгновенный список, но вместе с global создавало дубли; клиент Discord ещё и кэширует старые global до ~часа.

Имена в API — латиница. Русский клиент может показывать локализованные названия через `locale_str(..., ru=...)` и переводчик дерева.

> В Discord **нет** `/adminhelp` — это команда только Telegram. Справка по slash: таблица ниже и [[Команды]].

## Как устроено

1. После регистрации команд — глобальный `tree.sync()`.
2. При готовности гильдии — пустой guild sync (сброс серверных копий).
3. Повторный сброс той же гильдии в одном процессе пропускается.
4. Пока процесс не запущен, команды могут быть в списке, но не выполняются.

## Как проверить

1. Запустить бот с `DISCORD_TOKEN`.
2. В логе: `Слэш-команды (global) синхронизированы`, затем `Guild …: slash overrides cleared`.
3. Полностью выйти из Discord (из трея тоже) и открыть снова — сбросить кэш пикера.
4. В `/` у этого бота каждое имя один раз (латиница или RU-локаль — без дублей).

## Ограничения

- После смены набора команд глобальный список у клиента может обновляться до часа; guild-дубли снимаются сразу.
- Неверные scopes приглашения (`applications.commands`) команды не появятся.
- Telegram-команды (`/adminhelp`, `/admins`, `/addadmin`, …) в пикере Discord не появляются и не работают.
